DUTCH ACADEMY — стартовая версия

Содержимое:
- index.html — главная страница
- styles.css — оформление и адаптация под телефон
- app.js — работа урока, практики, словаря и прогресса
- data/words.json — стартовый словарь из 100 слов (A1)

Публикация на GitHub Pages:
1. Создай НОВЫЙ репозиторий, например dutch-academy.
2. Загрузи ВСЕ файлы и папку data, сохранив структуру.
3. В Settings → Pages выбери Deploy from a branch.
4. Выбери main и /(root), нажми Save.
5. Подожди несколько минут.

Важно:
- Не переименовывай index.html и папку data.
- Словарь должен лежать по адресу data/words.json.
- Прогресс хранится в браузере на конкретном устройстве. Синхронизация между устройствами пока не включена.
- Это первая основа проекта, не готовый полный курс A1–B1. Следующие уроки и темы будем добавлять поэтапно.
